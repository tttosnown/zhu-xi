# 筑习｜建筑学考研 Routine（V1 轻量 PWA）

这是第一版可运行原型，目标是先把核心学习流程跑通，不占用电脑大量内存。

## 已实现
- 本周 Routine / 今日任务
- 专业课按章节/知识模块输入
- 英语、政治可填写数量
- ★～★★★★★ 难度
- 每天/每周重复任务自动生成
- 专业课按科目自动生成 3～5 个主动回忆问题
- 主动回忆支持“输入答案”或“直接自评”
- 系统计算掌握率
- 完成率 / 掌握率 / 效率
- 本机 localStorage 数据保存
- JSON 数据导出
- 建筑规范入口（正式规范题库待接入你提供的 PDF）

## 关于 iPad 安装
本项目采用 PWA 结构。要在 iPad 上以“独立 App”方式加入主屏幕，需要把项目部署到 HTTPS 网站，然后在 Safari 中打开并选择“添加到主屏幕”。

## 重要限制
当前版本不能保证 App 在完全关闭时每天 20:00 进行系统级本地推送。iPadOS 的可靠系统级定时提醒需要原生 App 的本地通知，或 HTTPS + Web Push 服务端。

因此建议：
1. V1 先使用这个轻量 PWA 跑通学习逻辑；
2. 如果你确认界面和算法符合需求，再制作 V2 原生 iPadOS 版本；
3. V2 再加入真正可靠的 20:00 通知、Widget、iCloud。

## 规范
不要使用示例规范题作为正式学习依据。正式题库应根据用户指定的规范 PDF、版本和考试要求建立。
